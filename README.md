## 🌟 Featured Project

### 🧠 AI Resume Analyzer

A full-stack AI-powered resume analyzer system designed to analyze resumes, process structured data, and support intelligent resume evaluation workflows.

#### Built With

- **Frontend:** React + Vite
- **Backend:** NestJS + TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma
- **ML Service:** FastAPI + Python
- **Authentication:** JWT
- **Infrastructure:** Docker + Docker Compose

#### Key Features

- 🔐 Authentication and authorization
- 📄 Resume upload and analysis workflow
- 🧠 AI/ML service integration
- 🗄️ PostgreSQL database with Prisma ORM
- 🐳 Dockerized database setup
- ⚙️ Modular backend architecture
- 📦 Clean project structure
- 🧪 Sample data with Prisma seed
- 🚀 Deployment-ready structure
